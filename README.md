我目前在中央财经大学信息学院攻读人工智能硕士学位（2026 级推免，预计 2028 年毕业），此前于本校完成计算机科学与技术本科学习。

我的研究此前围绕**恶劣天气下的图像恢复与多模态融合**展开，尝试让视觉模型在雨、雾等退化场景下依然能看清并整合红外与可见光信息，部分相关工作已发表或录用于 [IEEE/CAA JAS](https://github.com/jiafeng-yan/TwoInOne-JAS) 与 [AAAI 2026](https://arxiv.org/abs/2511.12525)；近期也关注**多模态大模型的强化学习与自蒸馏**，相关工作包括已发表于遥感顶刊 [ISPRS JPRS](https://doi.org/10.1016/j.isprsjprs.2026.09.046) 的地理空间推理分割工作（[GRASP](https://arxiv.org/abs/2508.17102)）及超高分辨率遥感视觉问答（[RS-OPSD](https://arxiv.org/abs/2609.38072)）。

研究之外，我也会围绕视觉、检索与智能体做一些工程实践与课程构建，例如直播实时检索问答应用 [LiveStreamRAG](https://github.com/jiafeng-yan/LiveStreamRAG)、信鸽虹膜检测与端侧检索系统 [PigeonEye-AI](https://github.com/jiafeng-yan/PigeonEye-AI)、金融经济教学智能体 [FE-Teacher](https://github.com/jiafeng-yan/FE-Teacher) 以及本地文献检索系统 [InformationRetrieval_SearchEngine](https://github.com/jiafeng-yan/InformationRetrieval_SearchEngine)。
